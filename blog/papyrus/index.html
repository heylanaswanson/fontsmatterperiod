2009 Avatar. $237M budget.

Chris Costello drew it by hand over six months — on actual papyrus. Genuinely impressive craft. Then Microsoft bundled it into Office in 1996. Then James Cameron used it for Avatar in 2009. Ryan Gosling never recovered. Neither did we. The font is not the problem. The choices were.

Full write-up in progress. The carousel for Papyrus is live on Instagram — the long-form version lands here next. Add sections to body in fonts.json and rebuild.

Specimen above is set in Papyrus (system) — the real thing, not a stand-in. Where we can't license a typeface for web use, we say so.
