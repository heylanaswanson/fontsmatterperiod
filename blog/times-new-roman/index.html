Times New Roman

It was never meant to be beautiful. It was meant to be cheap.

#1 default on every word processor

The Times of London commissioned it in 1931 with one brief: fit more words per column inch. Not elegance. Not prestige. Economy. Stanley Morison directed it, Victor Lardent drew it, and it first set the paper the following year. It then became the default of academia, law, and bureaucracy worldwide — a cost-cutting measure mistaken for a standard.

The complaint that started it

In 1929 Stanley Morison — typographic adviser to Monotype, and a man constitutionally incapable of letting a bad letterform go — wrote that The Times of London was badly printed and set in a typeface that was behind the times. The paper's response was essentially: fine, you do it. Morison did not draw type himself. He directed. The actual drawing fell to Victor Lardent, a lettering artist in the paper's advertising department, working from Morison's specifications and a sample of Plantin as a starting point.

The brief was economy, not beauty

Every decision in Times New Roman serves one goal: more words in less space, still legible on cheap newsprint at speed. The letterforms are narrow. The x-height is large, so the face reads bigger than its point size and can be set smaller. The serifs are short and sharply cut, which survives the ink spread of high-speed rotary printing better than a delicate serif would. None of this is about elegance. It is a set of engineering answers to the problem of a newspaper column.

Why it became the default of everything

The Times first set the paper in it on 3 October 1932, and kept it as the house face for about forty years. Monotype then licensed it widely, and it arrived on the IBM Selectric, then on early laser printers, then as a Microsoft core font shipped with Windows. By the 1990s it was the thing a blank document opened in. An entire generation of academic papers, legal filings, and government forms is set in it — not because anyone chose it, but because nobody changed it.

The verdict

Times New Roman is not a bad typeface. It is an extremely good solution to a problem almost nobody has anymore. Nothing you write on a screen is competing for column inches on newsprint, so the compression that made it brilliant in 1932 now just makes it feel tight and a little grey. The crime is not using it. The crime is using it by default and calling that a decision.

Specimen above is set in Times New Roman (system) — the real thing, not a stand-in. Where we can't license a typeface for web use, we say so.
