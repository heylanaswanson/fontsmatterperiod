Futura

The font that went to the moon.

Classification
Geometric Sans
Year
1927
Designer
Paul Renner
Origin
Bauer Type Foundry, Frankfurt
1969 landed on the moon
~100 years old, still everywhere

Literally. The plaque left on the lunar surface by Apollo 11 is set in Futura. Paul Renner designed it in 1927 as pure geometry — circles, triangles, lines. No calligraphic history, no human hand, just math. NASA, IKEA, Volkswagen, Louis Vuitton. Still running the world.

Specimen above is set in Century Gothic / system Futura, not the original. We substitute when a typeface isn't licensable for web use — the letterforms you see will differ from the real thing.
